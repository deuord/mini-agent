## 五、Go↔Python 关键对照
- try/finally = defer；async with lock = Lock/Unlock（语法保证解锁）
- 异步生成器 async for + yield ≈ channel + range（边产生边消费）
- aclosing：Go 里没有对应（break 不会自动 close —— 9/29 死锁坑的根源）
- 异常机制与 if err!=nil 相反：Go 显式传错误，Python 抛出由上层接
- asyncio.to_thread ≈ go func()，但它是线程池不是协程
